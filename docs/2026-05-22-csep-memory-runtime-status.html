质量风险

  • receipt 时间字段校验太弱：占位符仍可通过 validation。
  • 坏 JSON 会直接导致 failed，说明 child worker 的 receipt 写入仍不稳。
  • low-value memory heuristic 会把某些真实偏好记录判成 partial，需要重新校准。
  • 旧 csep-synth-* 产物还在全局 skills 目录，但最近没有新 synthesis 定时任务运行迹象。

建议下一步

  • 补 validation：started_at / finished_at 必须是 UTC ISO 时间。
  • 把 receipt 写入失败分成空文件、坏 JSON、schema 错误三类，方便定位。
  • 把 low-value memory 检测从“关键词启发式”改为更窄的 duplicate/no-op 组合条件。
  • 单独做一次 global skills 清理报告：区分 csep-reflect-*、active csep-synth-*、retired/invalid csep-synth-*。
